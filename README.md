# aquakuler_program
Программа разработана в рамках курсового проекта по предмету ИСИТ 
для компании по доставке воды аквакулер

Для работы с базой данных postgressql необходимо создать файл .env в котором необходимо создать 
переменные для подключения к базе данных
USER = ""
PASSWORD = ""
HOST = ""
PORT = ""
DBNAME = ""

Запрос на создание начальной базы данных в файле CREATEDatabase.sql
